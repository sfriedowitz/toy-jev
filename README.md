# Toy Jev

A small PyTorch implementation exploring what a System One-style decision model could look like.

This project was inspired by [TypeSafe AI](https://typesafe.ai/?utm_source=chatgpt.com) 
and their [Jev / System One Models announcement](https://typesafe.ai/blog/introducing-system-one-models-and-jev?utm_source=chatgpt.com).    

## Disclaimer

**This is NOT an implementation of Jev or TypeSafe's actual model**.

TypeSafe has not publicly disclosed the full architecture or training procedure behind Jev. 
This repository is an independent toy implementation 
intended to explore one plausible architecture 
based on the publicly described interface and behavior.
